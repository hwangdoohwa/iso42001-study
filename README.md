# ISO 42001 오픈북 학습앱

문제 표현을 조항 번호와 연결하는 스마트폰용 학습 웹앱입니다. 15개 항목, 66개 문제 표현을 담았습니다.

- 문제 문장·조항·이유 통합 검색
- 조항 범위 / 전체·미완료·완료·중요 필터
- 답 가리기와 순서 섞기
- 학습 완료·중요 표시를 브라우저에 저장
- 스마트폰 공유 및 Markdown 내려받기

## 실행

설치나 빌드 없이 `index.html`을 열거나 정적 웹 호스팅에 이 폴더를 게시합니다. 공유 주소는 GitHub Pages에서 제공합니다.

## GitHub Pages

이 폴더 내용만 별도 저장소에 업로드한 뒤 저장소 설정의 Pages에서 `Deploy from a branch`, `main`, `/ (root)`를 선택합니다. `.nojekyll`을 포함합니다.

## 내용

강의 전사문에서 강조된 범위를 바탕으로 정리한 학습용 예시입니다. 표준 전문이나 실제 시험문제는 포함하지 않습니다. 해당 조항의 실제 교재 본문과 대조해 사용합니다. 용어 자료의 위치와 A.4의 세부 조항은 교재에서 확인합니다.

학습 상태는 기기·브라우저별로 저장되며 서버에 전송하지 않습니다. 저장이 제한된 브라우저에서는 기록이 유지되지 않을 수 있습니다.
